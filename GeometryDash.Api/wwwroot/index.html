Un nivel, varias revisiones

01 / Crear y editar

Un nivel tiene identidad estable y un borrador. Guarda con If-Match: "1". Una versión desactualizada devuelve 412; conserva tu copia local.

02 / Publicar

La publicación sella una revisión inmutable. Un borrador nuevo conserva la versión pública anterior. Los favoritos siguen al nivel; los votos, a cada revisión.

03 / Registrar partidas

El intento fija la revisión. Reenvía el mismo clientResultId y contenido al cerrar. Los resultados son ClientReported; no se verifica un replay.

Acceso y seguridad

Registra una cuenta y llama a POST /api/v1/auth/login. El Bearer dura 15 minutos; el refresh rota en una cookie HttpOnly con máximo absoluto de siete días. Login, refresh y logout requieren un encabezado Origin permitido. En desarrollo se permite HTTP local; producción exige HTTPS.

Solo el propietario accede a borradores. Para puntuar, termina un intento sobre una revisión ajena. Se admiten estrellas de 1 a 5. Una cuenta suspendida y una sesión revocada pierden acceso incluso con Bearer vigente.

Errores comunes

401 / 403
Sesión ausente o revocada, cuenta inactiva, rol u origen no permitido.
404
Nivel inexistente, privado, retirado o eliminado.
409
Estado o revisión cambiada, intento cerrado o resultado distinto.
412 / 428
Versión del borrador distinta / falta If-Match.
413 / 422
Solicitud demasiado grande / campos o geometría inválidos.
429
Espera el tiempo de Retry-After antes de reintentar.

Los errores contienen code y traceId. Nunca incluyas contraseñas ni tokens en reportes de errores.
